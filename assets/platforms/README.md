# Biểu tượng nền tảng

README sử dụng các biểu tượng từ [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0)
theo [giấy phép MIT đi kèm](LICENSE.devicon.txt). Các hình vector được chuyển sang màu trắng, đặt trên nền tối bo góc và lưu trực tiếp trong
repository để hiển thị rõ ở cả giao diện sáng/tối. Hình Linux dùng bản `plain` đơn sắc.

| File | Nguồn |

Tên và biểu tượng nền tảng thuộc chủ sở hữu tương ứng; việc sử dụng chỉ để nhận diện môi trường
của WMS, không ngụ ý chứng nhận hoặc bảo trợ. Phạm vi hỗ trợ và kiểm chứng nằm trong README chính.
