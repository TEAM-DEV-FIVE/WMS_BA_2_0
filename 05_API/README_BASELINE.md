# Hợp đồng API thiết kế cơ sở

[OpenAPI cơ sở](openapi_core.json) · [Thuyết minh thiết kế lưu trữ](BASELINE_NOTES.md) · [API hiện hành](README.md)

Hợp đồng cơ sở lưu các đề xuất payload, phân trang và nghiệp vụ của giai đoạn thiết kế. Những điểm chờ xác nhận trong thuyết minh là lịch sử, không thể hiện tính năng runtime hiện tại. Khi tích hợp client hoặc mô tả hệ thống đã triển khai, sử dụng [OpenAPI runtime](openapi_runtime.json).
